# 画面仕様

## S00：共通レイアウト

### 1. 機能
ログイン後の全画面（S03〜S06）に共通表示されるヘッダーとサイドバー。

| 機能 | 説明 |
|------|------|
| サイドバー開閉 | サイドバーの展開/折りたたみを切り替え |
| ナビゲーション | ホーム、キーワード検索、カテゴリ検索への遷移 |
| スレッド管理 | スレッド一覧表示、新規作成、タイトル変更、削除 |
| 通知 | 通知ポップアップ表示、既読処理 |
| 言語切り替え | 9言語から選択してUI言語を変更 |
| ログアウト | セッション破棄、ログイン画面へ遷移 |
| ロゴ | 滋賀県国際協会・社会知能研究室のロゴ、クリックで各ホームページへ |

### 2. エラー表示仕様

| No. | 発生条件 | 表示メッセージ | 表示場所 |
|-----|----------|----------------|----------|
| E01 | スレッド一覧取得失敗 | スレッドの取得に失敗しました | トースト |
| E02 | スレッド削除失敗 | スレッドの削除に失敗しました | トースト |
| E03 | 通知取得失敗 | 通知の取得に失敗しました | トースト |

### 3. 確認ダイアログ仕様

| No. | 発生条件 | 表示メッセージ |
|-----|----------|----------------|
| D01 | スレッド削除時 | スレッドを削除しますか？ |

## S04：キーワード検索画面

### 1. 機能

| 機能 | 説明 |
|------|------|
| キーワード検索 | キーワードを入力してQ&Aを検索 |
| 検索結果表示 | 該当Q&Aの一覧を表示 |
| Q&A詳細表示 | 検索結果からQ&Aの詳細を確認 |

前提条件：ログイン済みであること

制約事項：
- 検索はユーザーの設定言語と同じ言語のQ&Aのみが対象となる（例：日本語設定の場合、日本語のQ&Aのみヒットする）

### 2. エラー表示仕様

| No. | 発生条件 | 表示メッセージ | 表示場所 |
|-----|----------|----------------|----------|
| E01 | キーワードが空のまま検索 | キーワードを入力してください | フォーム下 |
| E02 | 該当Q&Aがない | 該当するQ&Aが見つかりませんでした。※検索は設定言語のQ&Aのみが対象です。 | 検索結果エリア |
| E03 | 検索API失敗 | 検索に失敗しました | トースト |

## S07：Not Found（404）画面

### 1. 機能

| 機能 | 説明 |
|------|------|
| 404エラー表示 | 存在しないURLにアクセスした際にエラーメッセージを表示 |
| ホームへ遷移 | ホーム画面（ログイン済み）またはログイン画面（未ログイン）へ戻るリンクを表示 |

表示条件：定義されていないURLパスにアクセスした場合（React Routerのワイルドカード `*` でキャッチ）

### 2. 表示仕様

| No. | 要素 | 表示内容 |
|-----|------|----------|
| D01 | エラーコード | 404 |
| D02 | メッセージ | ページが見つかりません / Page not found（設定言語に応じた表示） |
| D03 | 補足メッセージ | お探しのページは存在しないか、移動した可能性があります。 |
| D04 | 遷移リンク | ホームに戻る（ログイン済み→S03 / 未ログイン→S01） |

## S08：メンテナンス画面

### 1. 機能

| 機能 | 説明 |
|------|------|
| メンテナンス案内表示 | システムメンテナンス中であることをユーザーに通知 |

表示条件：環境変数 `MAINTENANCE_MODE=true` の場合、全画面アクセス時にメンテナンス画面を表示

### 2. 表示仕様

| No. | 要素 | 表示内容 |
|-----|------|----------|
| D01 | アイコン | メンテナンスアイコン（工具等） |
| D02 | メッセージ | ただいまメンテナンス中です / System is under maintenance（設定言語に応じた表示） |
| D03 | 補足メッセージ | ご不便をおかけして申し訳ございません。しばらくお待ちください。 |

## エラー表示ルール（共通）

| 表示場所 | 対象 | 表示方式 |
|----------|------|----------|
| フォーム下 | 入力バリデーションエラー | 入力欄直下に赤文字で表示 |
| トースト | 通信エラー、外部APIエラー、認証エラー | 画面右下にトースト通知（数秒後に自動消去） |
| 検索結果エリア / 一覧エリア | 該当なし | エリア内にメッセージ表示 |
