# これからの開発体制について

## Issue駆動開発
1. テスト仕様書にしたがってテストを実行（1回を4人で分担）
2. テスト項目で x となった部分をについて、Issueで報告
    * 「バグ」である場合は[Bug]で報告
    * 「機能として不足」している場合は[Feature]で報告
3. Issueにあるバグチケットが無くなるまで繰り返す


## チケットテンプレート

### バグ報告
```
---
name: "[Bug]"
about: バグの報告
title: "[Bug]"
labels: ''
assignees: ''

---

* 環境
ブラウザ：

* 再現手順

1. 
2. 
3. 

* 実動作（問題）

* 期待動作
```

### 機能追加の報告
```
---
name: "[Feature]"
about: 機能追加の要望
title: "[Feature]"
labels: ''
assignees: ''

---

* 環境
ブラウザ：

* 追加機能

* 期待動作
```
