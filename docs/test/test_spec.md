# テスト仕様書（システムテスト）

## システム名
ShigaChat

## 作成者


## 作成日（更新日）
2026/02/08

## テスト観点
以下の4観点についてテストを行う。

* UI：画面表示、レイアウト、ボタン動作、入力フォーム、エラー表示
* API：エンドポイントへのリクエスト/レスポンス、ステータスコード、認証
* DB：データの登録・取得・更新・削除、整合性
* 外部：OpenAI API連携（回答生成、翻訳、要約等）

## テスト環境

| 項目 | 内容 |
|------|------|
| サーバー | Docker Compose環境（app, nginx, db） |
| ブラウザ | Chrome, Firefox, Safari, Edge（最新版） |
| 画面解像度 | 1280×720以上 |
| ネットワーク | インターネット接続あり（OpenAI API利用） |
