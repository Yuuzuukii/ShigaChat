### nginxサーバーについて
nginxサーバーは静的ファイルの配信と、リバースプロキシ、ロードバランサーとしての役割がある

* 静的ファイルの配信：
SSRされるHTMLファイルの配信

* リバースプロキシ
外部ネットワークから、サーバーの情報を隠蔽する役割

* ロードバランサー
負荷分散を行う。複数のuvicornサーバーに適切に分散を行う。
nginx.confにて
upstream backend {
    server uvicorn:8000;
    server uvicorn:8001;
}
この設定を行うと、uvicorn:8000, 8001の順にリクエストを分散させる。
現在は、8000のサーバーのみなので、ロードバランサーは使っていない。


### uvicronサーバーについて
uvicornサーバーも、コンテナ数の増加、およびワーカーの増加によって負荷分散を行うことができる。
